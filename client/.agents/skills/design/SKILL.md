# Creating application design and visual identity skill

When modifying the design and/or visual identity follow these steps:

## Design checklist

1. **Precondition**: Before making any changes, take into account already present theming and Material UI styles, as well any .css files if present
2. **Styles**: Make the UI look modern yet not overblown
3. **Formatting**: Make sure that your changes adhere to common React formatting

## Forbidden actions

- **Business logic**: Do NOT modify business logic
